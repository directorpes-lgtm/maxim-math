# Математика Максима

Небольшой интерактивный тренажёр для 2 класса.

## Возможности
- Тренировки по 10 заданий и режим с четырьмя вариантами ответа
- Сложение и вычитание в пределах 100, сравнение, умножение и текстовые задачи
- Мгновенная проверка и объяснение решения
- Озвучивание заданий средствами браузера
- Сохранение прогресса на устройстве и повторение сложных тем

Сайт опубликован через GitHub Pages. Главная страница — `index.html`.
